# Sapol Chat System — แผน PDCA รอบที่ 2 (P)

> 26 ก.ย. 2026 · ต่อจากรอบที่ 1 (`PLAN.md` v0.3, `CHECK-ACT.md`) · เวลา ~50 นาที

## 1. เป้าหมาย

แก้ข้อจำกัดจากรอบที่ 1: รู้ว่าใครออนไลน์อยู่, ห้ามใช้ชื่อซ้ำ และเห็นว่าใครกำลังพิมพ์

## 2. ฟีเจอร์

| รหัส | ฟีเจอร์ | รายละเอียด |
|---|---|---|
| F4 | รายชื่อคนออนไลน์ | แถบด้านข้างแสดงชื่อทุกคนที่อยู่ในแชท พร้อมจำนวน อัปเดตทันทีเมื่อมีคนเข้า/ออก |
| F5 | กันชื่อซ้ำ | ถ้าชื่อซ้ำกับคนที่ออนไลน์อยู่ (ไม่สนตัวพิมพ์เล็ก/ใหญ่) จะเข้าไม่ได้ และขึ้นข้อความบอกให้เปลี่ยนชื่อ |
| F6 | "กำลังพิมพ์…" | แสดงเหนือช่องพิมพ์ เช่น "Ann กำลังพิมพ์…" หายไปเมื่อหยุดพิมพ์ 1.5 วินาที หรือส่งข้อความแล้ว |

## 3. การออกแบบ

**ข้อมูลฝั่ง server:** `users = Map(socket.id → name)` เก็บในหน่วยความจำ

**Events ที่เพิ่ม/เปลี่ยน**

| ทิศทาง | Event | ข้อมูล | ความหมาย |
|---|---|---|---|
| เบราว์เซอร์ → server | `join` | `name`, `callback` | เปลี่ยน: server ตอบกลับ `{ ok: true, history }` หรือ `{ ok: false, error }` |
| เบราว์เซอร์ → server | `typing` | `true` / `false` | เริ่ม/หยุดพิมพ์ |
| server → เบราว์เซอร์ | `users` | `[name...]` | รายชื่อคนออนไลน์ (ส่งหาทุกคน) |
| server → เบราว์เซอร์ | `typing` | `{ name, isTyping }` | ส่งหาทุกคน **ยกเว้นคนพิมพ์** (`socket.broadcast`) |

> ยกเลิก event `history` แยก เพราะส่งไปพร้อมคำตอบของ `join` แล้ว

**หน้าจอ**

```
┌─ Sapol Chat ────────────────────────────── HAT ─┐
│ ออนไลน์ (3) │ Ann 10:02  สวัสดี                  │
│ ● HAT       │ — Bob เข้าห้อง —                   │
│ ● Ann       │                                   │
│ ● Bob       │ Ann กำลังพิมพ์…                     │
│             │ [ พิมพ์ข้อความ...        ] [ส่ง]    │
└─────────────┴───────────────────────────────────┘
หน้าเข้าแชทเมื่อชื่อซ้ำ: ชื่อ "Ann" มีคนใช้อยู่แล้ว ลองชื่ออื่น
```
มือถือ (จอแคบ): รายชื่อย้ายไปเป็นแถบบรรทัดเดียวด้านบน

## 4. แผนงาน (Do)

| นาทีที่ | งาน |
|---|---|
| 0–15 | server: `users` Map, `join` แบบ callback + เช็กชื่อซ้ำ, ส่ง `users` ตอนเข้า/ออก |
| 15–30 | client: รอคำตอบ `join`, แสดง error, แถบรายชื่อออนไลน์ |
| 30–45 | typing: ส่ง `typing` ตอนพิมพ์, หยุดเมื่อเงียบ 1.5 วิ/ส่งข้อความ/ออกจากแชท |
| 45–50 | ทดสอบ |
