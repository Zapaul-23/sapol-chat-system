# Sapol Chat System — แผนงาน (P ของ PDCA)

> เวอร์ชัน 0.3 (ฉบับย่อ · ห้องเดียว) · 26 ก.ย. 2026 · สถานะ: **Plan**
> เงื่อนไข: ใช้ในการเรียน ไม่ซับซ้อน ต้องทำเสร็จภายใน **1 ชั่วโมง**

---

## 1. เป้าหมาย

สร้างเว็บแชทแบบเรียลไทม์ **ห้องเดียว** ด้วย Node.js + Socket.IO เพื่อเรียนรู้หลักการทำงานของ WebSocket และ event

**จบงานเมื่อ:** เปิดเบราว์เซอร์ 2 แท็บ ตั้งชื่อ แล้วเห็นข้อความของกันและกันทันที

## 2. ขอบเขต

| ทำ (3 ฟีเจอร์) | ไม่ทำ |
|---|---|
| F1 ตั้งชื่อก่อนเข้าแชท | หลายห้อง / สร้างห้อง |
| F2 ส่งและรับข้อความเรียลไทม์ พร้อมชื่อและเวลา | ฐานข้อมูล (ใช้ array ในหน่วยความจำแทน) |
| F3 แจ้ง "xxx เข้าห้อง / ออกจากห้อง" | รายชื่อคนออนไลน์, "กำลังพิมพ์…" |
| (แถม) เข้ามาแล้วเห็นข้อความล่าสุดไม่เกิน 50 ข้อความ ตราบที่ server ยังไม่ปิด | ล็อกอิน, เช็กชื่อซ้ำ, กันสแปม, test อัตโนมัติ |

**ข้อกำหนดขั้นต่ำด้านความปลอดภัย:** แสดงข้อความด้วย `textContent` เท่านั้น (ห้ามใช้ `innerHTML`) เพื่อกันการฝังสคริปต์ (XSS) และตัดข้อความว่างทิ้ง

## 4. การออกแบบ

### 4.1 โครงสร้างระบบ

```
เบราว์เซอร์ (index.html)  ⇄  WebSocket  ⇄  server.js (Express + Socket.IO)
                                              └─ history = []   (เก็บ 50 ข้อความล่าสุด)
```

ทุกคนที่เชื่อมต่ออยู่ในห้องเดียวกัน server ใช้ `io.emit(...)` ส่งหาทุกคนได้เลย ไม่ต้องใช้ rooms

### 4.2 Events

| ทิศทาง | Event | ข้อมูล | ความหมาย |
|---|---|---|---|
| เบราว์เซอร์ → server | `join` | `name` | เข้าแชทด้วยชื่อนี้ |
| เบราว์เซอร์ → server | `chat` | `text` | ส่งข้อความ |
| server → เบราว์เซอร์ | `history` | `[ข้อความ...]` | ข้อความเก่า (ส่งให้คนที่เพิ่งเข้า) |
| server → เบราว์เซอร์ | `chat` | `{ name, text, time }` | ข้อความใหม่ |
| server → เบราว์เซอร์ | `system` | `text` | แจ้งเข้า/ออก |

### 4.3 หน้าจอ

```
┌─ หน้าเข้าแชท ──────────┐      ┌─ หน้าแชท ───────────────────────┐
│  Sapol Chat            │      │ Sapol Chat               HAT    │
│  ชื่อ: [ HAT        ]   │  →   │ Ann 10:02  สวัสดี                │
│  [ เข้าแชท ]            │      │ — Bob เข้าห้อง —                 │
└────────────────────────┘      │ HAT 10:03  หวัดดี                │
                                │ [ พิมพ์ข้อความ...      ] [ส่ง]   │
                                └─────────────────────────────────┘
```

## 5. แผนการทำงาน (ขั้น Do) — รวม 60 นาที

| นาทีที่ | งาน | ตรวจได้ว่าเสร็จเมื่อ |
|---|---|---|
| 0–10 | `npm init -y` แล้ว `npm install express socket.io` | มีโฟลเดอร์ `node_modules` |
| 10–25 | เขียน `server.js`: เสิร์ฟ `public/`, รับ `join` / `chat`, ส่งต่อให้ทุกคน | `node server.js` ขึ้นข้อความ "running on 3000" |
| 25–45 | เขียน `index.html`: หน้าเข้าแชท, กล่องข้อความ, ช่องพิมพ์ | เปิด http://localhost:3000 แล้วส่งข้อความได้ |
| 45–50 | ใส่ CSS ให้อ่านง่าย | ข้อความของเราแยกสีจากของคนอื่น |
| 50–60 | ทดสอบตามข้อ 6 | ผ่านครบ 5 ข้อ |

## 7. ความเสี่ยง

| ความเสี่ยง | แนวทาง |
